SECTION 1: WHAT IS NITYAGEETA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

NityaGeeta is an AI-powered conversational platform that allows users to seek
wisdom from the Bhagavad Gita through natural conversation. "Nitya" (Sanskrit)
means "eternal" — the eternal teachings of the Gita.

PRIMARY PURPOSE:
  A user can ask any question about life, duty, karma, purpose, relationships,
  fear, ego, or any philosophical topic — and NityaGeeta answers drawing from
  authenticated Gita commentary sources, not from general AI knowledge.

WHO IT SERVES:
  - Students of Vedic philosophy
  - People seeking clarity during difficult life situations
  - Devotees who want to understand specific shlokas
  - Entrepreneurs and professionals exploring dharmic principles

SOURCE MATERIAL (Knowledge Base):
  1. Bhagavad Gita with Commentary of Adi Shankaracharya (English)
     — Oldest and most authoritative Advaita Vedanta commentary
  2. Gita Sadhak Sanjeevani (English Edition)
     — Swami Ramsukhdas commentary, most popular in India
  3. Srimad Bhagavad Gita — Gita Press Gorakhpur (Hindi + Sanskrit)
     — The gold-standard Hindi edition used by millions
  4. The Bhagavad Gita — Winthrop Sargeant (Word-for-Word English)
     — Academic, verse-by-verse English translation

TECHNOLOGY STACK (simplified):
  Frontend : HTML, CSS, Vanilla JavaScript (no frameworks)
  Backend  : Python FastAPI
  Database : Neon PostgreSQL (user data, conversations, messages)
  Cache    : Redis (sessions, fast lookups)
  AI       : OpenRouter API (Claude/GPT-4) for conversations
  AI Memory: Full conversation history stored in PostgreSQL

SECTION 2: DESIGN PRINCIPLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Inspired by: Apple.com, Linear.app, Perplexity AI
Theme concept: Aged gold leaf on temple stone — sacred but refined

CORE RULES:
  1. Restraint — every element earns its place. No decorative noise.
  2. Whitespace is structural — sections breathe, nothing feels cramped.
  3. One accent color (gold) — used sparingly, never everywhere.
  4. Typography carries hierarchy — size and weight do the work.
  5. Hover states: single property only (opacity or slight background lift).
  6. Sacred imagery from Krishna, Vishnu, Mahabharata — for cultural trust.

COLOR PALETTE:
  Background main  : #0b0a10  (deep near-black, cool undertone)
  Background card  : #131220  (slightly lifted dark surface)
  Background alt   : #0e0d16  (alternating section tone)
  Gold primary     : #c9a455  (aged gold leaf — main accent)
  Gold dim         : #8a6d35  (muted gold for secondary elements)
  Gold border      : rgba(201,164,85,0.16)
  Gold glow        : rgba(201,164,85,0.05)
  Cream primary    : #ede0c4  (parchment — main text)
  Cream secondary  : #9e9280  (subtitles, captions)
  Cream faint      : #5c5448  (labels, disabled states)
  Border line      : rgba(255,255,255,0.06)

TYPOGRAPHY:
  Headings   : Cinzel (400–700 weight) — Roman, ancient, authoritative
  Body text  : Crimson Pro (300–600 weight) — Elegant serif, readable
  Sanskrit   : Noto Sans Devanagari (300–400 weight) — Verse display
  (All from Google Fonts, loaded via CDN — no local file required)

ANIMATIONS POLICY (strict):
  ALLOWED:
    - Cursor golden glow (lerp 0.3 speed — fast, no lag)
    - Om symbol gentle float (5s, ease-in-out, infinite, 10px movement)
    - Hero background slow drift (40–45s, scale 1.06–1.08, barely visible)
    - Scroll reveal: single fade-up (opacity 0→1, translateY 20px→0, once)
    - Hover states: border-color or background change only (0.25s transition)
    - Step number hover fill on How It Works section
  NOT ALLOWED:
    - Canvas particles / sacred geometry floating
    - Loading screens / splash animations
    - Staggered card animations
    - Rotating rings or orbital shapes
    - Magnetic cursor-following effects
    - Shimmer on text / gradient text animation

OBSERVED FROM OTHER SPIRITUAL/GITA PLATFORMS:

1. GitaSupersite (Kurukshetra University)
   Layout: Basic academic — header nav, left sidebar for verse selection,
           right content area. No design — purely functional.
   What to borrow: Verse-reference system (chapter.verse notation)
   What to avoid: The entire visual design

2. Gitasaar.com
   Layout: Header with logo, full-width hero with Sanskrit verse banner,
           then tabbed content (Shlokas / Meaning / Commentary).
   What to borrow: Shloka-meaning-commentary separation pattern
   What to avoid: Flat colors, no hierarchy

3. Bhagavad-Gita.org
   Layout: Image-heavy header, Sanskrit text prominently displayed,
           commentary below in two columns.
   What to borrow: Two-column commentary layout
   What to avoid: Cluttered header

4. Perplexity AI (inspiration for chat interface)
   Layout: Left sidebar (conversation history), center chat area,
           clean message bubbles, source citations shown below answers.
   What to borrow: Source citation display, clean chat bubbles
   What to adapt: Replace their minimal white with our dark gold theme

5. Anthropic Claude (inspiration for chat input area)
   Layout: Input at bottom, messages fill upward, no fixed sidebar nav.
   What to borrow: Bottom input bar style, full-height chat container

DESIGN DIFFERENTIATORS FOR NITYAGEETA (what no one else has done):
  - Golden cursor glow that moves with the user — connects to divine presence
  - Verse banner with Sanskrit AND English on landing page mid-section
  - Two-panel auth pages (image left, form right) — sacred image anchors trust
  - Chapter.Verse reference shown inline in AI responses like footnotes
  - Full conversation history — no AI memory loss ever

  Element: fixed div, 480×480px circle, pointer-events none
  Color: radial-gradient gold at 0% → transparent at 68%
  Opacity of gold: 0.05 (subtle, not distracting)
  Movement: lerp factor 0.3 (very fast, feels immediate)
  Disabled: on touch devices (ontouchstart detection)
  Code: requestAnimationFrame loop, not setInterval

FLOATING LABELS (all form inputs):
  Label sits at vertical center of input by default
  On focus OR when value is entered: label moves to top (0.5rem from top)
  Label font: Cinzel, 0.65rem → 0.55rem on float, letter-spacing 0.12em
  Transition: all 0.25s cubic-bezier(0.0, 0.0, 0.2, 1)

  Display: block (hidden by default)
