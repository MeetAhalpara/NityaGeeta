# Design & Raw Asset Storage (`/frontend/assets/`)

The `assets/` directory contains source design assets, raw landing page graphics, design mockups, and icon assets used during frontend development.

---

## Subdirectory Overview

```
frontend/assets/
├── LandingPage/    # Raw graphics & hero assets for the landing page
├── design/         # UI design mockups & color token reference assets
├── icons/          # Raw SVG icon files
└── images/         # High-resolution brand graphics
```
