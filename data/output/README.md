# Processed Scripture Datasets (`data/output/`)

The `data/output/` directory contains all canonical scripture datasets, commentaries, and OCR book handbooks used by NityaGeeta's Retrieval-Augmented Generation (RAG) engine.

---

## Subdirectory Overview

```
data/output/
├── gita_editions/          # Canonical Bhagavad Gita editions & historical commentaries
└── veducation_books/       # Veducation OCR handbooks (BOSS, Brahmacharya, Vedic Dincharya)
```

1. [**`gita_editions/`**](file:///c:/Users/Meeta/OneDrive%20-%20Algonquin%20College/Subjects/6/Entrepreneurship/NityaGeeta/data/output/gita_editions/README.md):
   * Contains the complete 1,296-page translated Gita Press *Sadhaka-Sanjivani*, Adi Shankaracharya's Advaita commentary, Winthrop Sargeant's word-for-word Sanskrit dictionary, and raw OCR files.

2. [**`veducation_books/`**](file:///c:/Users/Meeta/OneDrive%20-%20Algonquin%20College/Subjects/6/Entrepreneurship/NityaGeeta/data/output/veducation_books/README.md):
   * Contains OCR text datasets from the Veducation library (*Basics of Sanatan Sanskriti - BOSS*, *Brahmacharya*, *Vedic Dincharya*) used for page-level citations and the interactive Scripture Reader Modal.
